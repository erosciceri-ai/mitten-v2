# Política de seguridad

MITTEN V2 es un prototipo educativo y no un dispositivo médico certificado.

## Reportar una vulnerabilidad

No publiques credenciales, datos personales ni detalles explotables en un issue público. Reporta el problema de forma privada al responsable del repositorio mediante las opciones de contacto de su perfil de GitHub.

Incluye, cuando sea posible:

- componente y versión afectados;
- pasos mínimos para reproducir el problema;
- impacto esperado;
- propuesta de mitigación.

## Alcance

Se consideran especialmente relevantes la autenticación, autorización, exposición de datos locales, validación de mensajes serie, manejo de archivos de audio y dependencias vulnerables.
