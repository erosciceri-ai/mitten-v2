## Orchestration Protocol

### Before ANY Task

```bash
cd v2
git status
git branch
git worktree list
git log --oneline -n 10
```

### Task Delegation to OpenCode

Create a self-contained prompt with:
- Objective (one sentence)
- Minimal necessary context
- Relevant files (paths + what to modify vs reference)
- Scope (include/exclude)
- Acceptance criteria (testable)
- Mandatory validations (test commands, build commands)
- Constraints: work ONLY in `../v2-opencode`, no commits, stop on contradictions

Execute:
```bash
cd ../v2-opencode
opencode run '<prompt>' --workdir .
```

### After OpenCode Completes

```bash
cd ../v2-opencode
git status
git diff
npm test && npm run build  # or relevant workspace tests
```

### Reporting to User

Always provide, in order:
1. **Root cause** (one sentence, or "not investigated")
2. **Files modified** (path by path, what changed)
3. **Tests executed** (command + actual result)
4. **Pending & risks** (what's not done, contradictions found with citations)

Distinguish: **documented** (canonical doc + citation) / **implemented** (in code) / **inferred** (your conclusion).

## Stack Decisions (CLOSED — Do Not Reopen)

- Firmware: **MicroPython** on ESP32 (modular, not monolithic)
- Backend: **Node.js + Express + TypeScript + SQLite**
- Frontend: **React + Vite + TypeScript**
- Communication: **Web Serial API** from frontend only (no `monitor.py`, no bridge)
- Protocol: **NDJSON UTF-8 + LF, Protocol Version 2**
- Max message: **8192 bytes**, no fragmentation

## Prohibited Patterns

- Mass rewrites without inspection → understand → plan → implement → test → review
- PostgreSQL, MongoDB, Redis, microservices, cloud infra
- `monitor.py`, local bridges, independent serial connections
- Hardcoded URLs, secrets, SQL in controllers, silent catches, unjustified `any`
- Committing `.env`, tokens, JWT secrets, passwords, API keys
